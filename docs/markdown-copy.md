# 选择并复制 Markdown 源码

阅读区的选区关联原文件的源码位置。复制使用这些原始片段，不从屏幕文字反推 Markdown；文件本身保持只读。

## 操作

- 拖动鼠标选择文字，可跨段落、图片、表格、代码块和公式；反向拖选同样支持。
- 双击普通文字选择词，三击选择当前段落；Shift+单击扩展原选区。
- 拖到阅读区上方或下方会继续滚动并扩展选区。
- Ctrl+C 复制所选 Markdown，Ctrl+A 选择整个原文件，Escape 清除选区。
- 右键提供“复制所选 Markdown”“复制此块 Markdown”“复制整篇 Markdown”。
- 代码块右上角的复制按钮也复制完整围栏语法。

## 结构规则

| 内容 | 复制结果 |
| --- | --- |
| 普通文字、折行段落 | 所选源码片段；局部强调会补齐 `**` 等标记 |
| 标题、引用、任务文字 | 保留对应的标题、引用、列表和任务前缀 |
| Markdown 图片 | 原来的 `![说明](路径 "标题")`，不复制位图或只复制说明 |
| HTML 图片 | 保留原 `<img>` 标签及其属性 |
| 行内代码、链接、行内公式 | 按完整语法单元选择，保留反引号、链接地址和公式分隔符 |
| 代码块 | 整个原始代码块，保留语言、围栏长度、反引号/波浪线样式及换行 |
| 表格 | 整个原始 Markdown 表格，保留对齐分隔行、转义竖线和单元格中的语法 |
| HTML 块、块级公式 | 原始 HTML 或 TeX 源码，包括标签、属性、公式分隔符 |
| 引用式链接/图片、脚注 | 复制引用并附带所需定义，使粘贴后的 Markdown 仍可解析 |

为了保留完整结构，表格、代码块、HTML 块和公式按完整语法节点选取。长代码块或大表格即使被虚拟化拆成多段，也只复制一次原始节点。极长段落的性能分片同样以完整原段落复制。普通文本文件支持局部文字选择。

剪贴板提供 Unicode 文本及 `text/markdown`、`text/x-markdown`。不提供渲染后的 HTML 或 Bitmap，避免粘贴目标把源码换成富文本或图片。相对链接保持原样，不擅自改成绝对路径。

## 实现与验证

- `MarkdownEngine` 记录源码范围并启用精确行内位置，多个视觉分片共享原始节点范围。
- 选择状态保存文档位置，不保存可回收容器；全选直接复用原文件字符串，滚动不会丢失选区。
- 选区装饰只绘制屏幕附近的容器；布局位置未变化时不反复触发重绘。
- 专项检查源码保真、边界标记、实际文字/图片/公式命中、拖选、快捷键、剪贴板载荷及长文回收；不会为测试改写用户系统剪贴板。
